# RSI / Brain Analytics Dashboard

Static HTML dashboard for OpenCrabs RSI (Recursive Self-Improvement) and brain file analytics. Generated by Python script, delivered however you want.

**The generator is read-only** — it reads your OpenCrabs data and writes a single `index.html`. Nothing else is modified.

## Features

- **Brain file sizes** — KB + lines, with time-series history from `.bak` files
- **Tool usage stats** — most/least used, failure rates, stacked success/failure charts
- **RSI tracking** — applied improvements per tool, mention rates, cumulative timeline
- **Scatter plot** — usage vs failure rate, bubble size = RSI applied, color scale
- **Profile switcher** — auto-discovers all profiles under `~/.opencrabs/profiles/` plus the root profile
- **Expandable charts** — click any chart header to toggle full-width

## Usage

```bash
# Generate dashboard
python3 ~/.opencrabs/analytics/gen_dashboard.py

# Output: ~/.opencrabs/analytics/index.html
```

Open `index.html` in a browser, serve it, or send it however you like.

## Cron (manual setup)

The cron job is **not** created automatically. You need to set it up yourself using OpenCrabs cron.

Example cron prompt (upload to a paste service and reply with the link):

```
Run python3 ~/.opencrabs/analytics/gen_dashboard.py to generate the dashboard,
then upload ~/.opencrabs/analytics/index.html to litterbox.catbox.moe via:
curl -F 'reqtype=fileupload' -F 'time=72h' -F 'fileToUpload=@~/.opencrabs/analytics/index.html' https://litterbox.catbox.moe/resources/internals/api.php
Then reply with ONLY the URL.
```

Adjust the delivery method to your setup (Telegram, Slack, webhook, etc.).

## Data Sources

- Brain files: `~/.opencrabs/profiles/{profile}/`
- SQLite: `~/.opencrabs/opencrabs.db` (tool_executions, feedback_ledger)
- RSI logs: `~/.opencrabs/rsi/improvements.md` + `history/*.md`

## Dependencies

- Python 3 (no pip packages — stdlib only)
- Chart.js + chartjs-adapter-date-fns via CDN (in generated HTML)
